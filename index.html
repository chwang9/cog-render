实际调用代码

import { COGLayer, COGSource }
  from '@developmentseed/deck.gl-geotiff';

// 预打开并缓存，复用同一 source
// 可跳过 header 读取且不重置瓦片
const src = await COGSource.open(COG_URL);

const layer = new COGLayer({
  id: 'cog',
  source: src,             // v0.9 是 geotiff:
  onTileLoad: () => n++,   // 瓦片进度
  onTileError: () => e++,
});

new Deck({
  canvas, controller: true,
  layers: [layer],
});

v0.10 把 geotiff 改为 source、onGeoTIFFLoad 改为 onSourceLoad。合并请求与流式解码由内置 range reader 完成，无需手动配置。默认 maxRequests:256 / debounceTime:50ms，6 请求每域名限流。
